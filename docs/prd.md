## 02. 만드는 것 / 만들지 않는 것

### ✅ 만든다

| 기능 | 설명 |
|---|---|
| 대시보드 | 마인드맵 목록 조회, 생성, 삭제 |
| 에디터 | 노드 추가/수정/삭제/이동, 자유 배치 |
| 캔버스 조작 | 줌, 패닝 (PC: 마우스 휠 / Mobile: 핀치·드래그) |
| 모바일 FAB | 키보드 없는 환경에서 노드 추가 전용 버튼 |
| 자동 저장 | 변경 시마다 IndexedDB에 즉시 저장, 새로고침 후 복구 |
| PC 단축키 | `Tab` 자식 추가, `Enter` 형제 추가, `Backspace/Delete` 삭제 |

### ❌ 만들지 않는다

- 실시간 협업 / 동시 편집
- 노드 폰트·색상 커스터마이징 (단일 테마 고정)
- 서버 동기화 / 클라우드 저장
- PDF·이미지 내보내기
- 폴더 구조 / 외부 공유
- 음성 입력 / AI 생성

## 03. 우선순위

바이브 코딩 특성상 작업 순서와 디버깅 집중도를 명확히 고정한다.

```
P0 — 모바일 터치 UX (핀치줌, 패닝, FAB)
P1 — IndexedDB 자동 저장 / 복구
P2 — 노드 CRUD
P3 — PC 단축키
```

> P0, P1이 불안정한 상태에서 P3를 완성해도 QA를 통과하지 못한다.
> 막히면 아래 순서로 내려가지 말고, 위 항목을 먼저 안정화한다.

## 04. 화면 구성

### 랜딩
- '시작하기' 버튼 → 대시보드 이동

### 대시보드
- 마인드맵 카드 목록 (썸네일 없음, 텍스트 기반)
- `+ 새 마인드맵` 버튼
- 카드 클릭 → 에디터 이동
- 카드 삭제 버튼

### 에디터
- 중앙 Root 노드가 배치된 무한 캔버스
- 상단 헤더: 홈 버튼
- 모바일: FAB(+) 버튼
- 노드 선택 시: 삭제 액션 메뉴
- 자동 저장 (별도 저장 버튼 없음)
